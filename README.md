# PasteGuard 0.2.1 — free experimental preview

Local pattern redaction with an ON/OFF switch for selected text inputs on ChatGPT, Claude, and Gemini. Starts OFF. Switching OFF does not restore removed text.

This repository is being prepared for a free test release. No payments or paid team features are available.

## Status

25 scanner checks and 18 browser fixture checks passed. Installed Chrome and live AI-editor compatibility remain unverified. A fixture is not a production compatibility test.

This is not protection for every app or every sensitive detail. A destination may read text before a pattern is recognized. Rich-text replacement can flatten formatting. No complete leak-prevention or guaranteed response-time claim is made.

## Installation

When the release is published, download its source ZIP, extract it, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extension folder containing manifest.json. Reload the supported AI tab. Test ON/OFF using fabricated examples only. Follow your company installation policy.

## Voluntary feedback

Use Issues to report installation trouble, repeat use, false alarms, or editor failures. Issues are public. Never include real secrets, private code, customer prompts, or personal information.

## Privacy

Scanning is local. No outbound scanning requests, AI API, analytics, or saved snippets. The extension stores only the ON/OFF preference. Other websites, extensions, and clipboard history remain outside its control.
