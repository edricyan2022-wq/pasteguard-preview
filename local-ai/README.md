# Local AI test program

See the top-level README.md for installation, ON/OFF behavior, and limitations.
This runs only on this computer. Setup downloads model files once; inference has no network calls.
The model and full revision are documented in setup.py. The raw-AI fake-data audit is in AUDIT.json.
The model is not guaranteed to catch all secrets. Names and locations work on our local examples;
password/API key misses remain in the audit. Pattern rules are retained alongside AI.
This is not protection for every desktop app. No payment service is available.
